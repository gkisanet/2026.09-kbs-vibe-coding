# KBS 청주방송총국 AI 바이브 코딩 실무 교육

본 교육 과정은 프로그래밍 경험이 없는 방송 기술진과 사내 임직원이 **AI를 파트너로 활용하여 사내 업무 자동화 프로그램을 직접 설계하고 개발**할 수 있도록 돕는 실습형 커리큘럼입니다.

코드를 한 줄씩 직접 외워서 짜는 대신, AI에게 명확한 맥락과 지침을 전달하여 고품질의 소프트웨어를 완성하는 **바이브 코딩(Vibe Coding)** 방식을 학습합니다.

---

## 3단계 학습 흐름

교육은 아래의 3단계를 순서대로 진행합니다:

```text
[1단계] AI와 대화하는 법 ──▶ [2단계] 협업 개발 실습 ──▶ [3단계] 사내 실무 앱 완성
(마크다운·위키·AI 이해)     (화면·서버·DB 연결)        (ERP 자동화 크롬 확장앱)
```

1. **1단계: AI와 대화하는 법 (`1.교육자료`)**
   - AI와의 가장 효율적인 대화 형식인 **마크다운(Markdown)** 기본 문법을 익힙니다.
   - 공부하다 어려운 개념이 나오면 AI에게 나만의 보충 위키(`wiki/`)를 작성하게 하여 **교육자료를 스스로 확장하는 방법**을 체득합니다.
   - 이를 바탕으로 **AI의 본질과 LLM 동작 원리, Context 관리 기법**을 깊이 있게 이해합니다.

2. **2단계: 협업 개발 실습 (`2.AI_APP`)**
   - 화면(Frontend), 서버(Backend), 데이터베이스(DB)가 연결되는 **3-Tier 기본 구조**를 이해합니다.
   - `v1`(기본 실시간 채팅앱)을 바탕으로, `v2`(확장앱)에서 **AI Agent를 탑재하여 채팅 대화 내용을 자동으로 요약해 주는 기능**을 AI와 함께 단계별로 개발합니다.

3. **3단계: 사내 실무 앱 완성 (`3.autoreport_크롬확장앱`)**
   - 2단계에서 독립된 웹 애플리케이션을 만들었다면, 3단계에서는 **웹 브라우저 화면을 직접 제어하고 조작하는 크롬 확장 프로그램**을 개발합니다.
   - 실제 KBS 사내 ERP의 반복적인 업무일지 입력 작업을 클릭 한 번으로 자동화하는 실무 프로그램을 클론 코딩하고 분석합니다.

---

## 폴더 구성 및 역할

- **`1.교육자료/`**: 마크다운 작성법, 나만의 위키 확장 가이드, AI 기본 이해 및 Context 실습 교재
- **`2.AI_APP/`**: 3-Tier 기본 채팅앱(v1) 및 AI 대화 요약 기능 확장 실습(v2) 샌드박스
- **`3.autoreport_크롬확장앱/`**: 실제 사내 업무 자동화 크롬 확장 프로그램 소스 및 단계별 자습 교재
- **`docs/`**: 프로젝트 아키텍처, 변경 이력, 트러블슈팅 오답 노트

---

## 학습 시작 방법

1. **`1.교육자료` 폴더**의 문서부터 번호 순서대로 읽기 시작합니다.
2. 교재를 읽다가 모르는 개념이 나오면 `0-3. 나만의_AI_학습위키_확장가이드.md`의 프롬프트를 복사하여 AI에게 질문합니다.
3. **`2.AI_APP`**과 **`3.autoreport_크롬확장앱`** 실습 단계로 넘어가 AI와 함께 실제 프로그램을 실행하고 수정해 봅니다.

## 권장 환경

- **브라우저**: Google Chrome (개발자 모드 활성화)
- **런타임**: Node.js v20 이상
- **개발 도구**: Antigravity IDE 또는 VS Code
- **AI 서비스**: OpenRouter, Google Gemini, Anthropic Claude
