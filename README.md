# KBS 청주방송총국 AI 바이브 코딩 실무 교육

본 교육 과정은 프로그래밍 경험이 없는 방송 기술진과 사내 임직원이 **AI를 파트너로 활용하여 사내 업무 자동화 프로그램을 직접 설계하고 개발**할 수 있도록 돕는 실습형 커리큘럼입니다.

코드를 한 줄씩 직접 외워서 짜는 대신, AI에게 명확한 맥락과 지침을 전달하여 고품질의 소프트웨어를 완성하는 **바이브 코딩(Vibe Coding)** 방식을 학습합니다.

---

## 3단계 학습 흐름

교육은 아래의 3단계를 순서대로 진행합니다:

```text
[1단계] AI와 대화하는 법 ──▶ [2단계] 협업 개발 실습 ──▶ [3단계] 사내 실무 앱 완성
(원리 이해 & 지시법)         (화면·서버·DB 연결)        (ERP 자동화 크롬 확장앱)
```

1. **1단계: AI와 대화하는 법 (`1.교육자료`)**
   - AI의 동작 원리를 이해하고, 가장 효율적인 마크다운 형식으로 지시하는 방법을 배웁니다.
   - 공부하다 어려운 개념이 나오면 AI에게 나만의 보충 위키(`wiki/`)를 작성하게 하여 학습합니다.

2. **2단계: 협업 개발 실습 (`2.API_TEST`)**
   - 화면(Frontend), 서버(Backend), 데이터베이스(DB)가 서로 데이터를 주고받는 전체 구조를 AI와 함께 단계별로 만듭니다.

3. **3단계: 사내 실무 앱 완성 (`3.autoreport_크롬확장앱`)**
   - 실제 KBS 사내 ERP 업무일지 입력 작업을 자동화하는 크롬 확장 프로그램을 클론 코딩하고 분석합니다.

---

## 폴더 구성 및 역할

- **`1.교육자료/`**: AI 기본 이론, 마크다운 읽기/작성법, 나만의 위키 확장 가이드
- **`2.API_TEST/`**: 프론트엔드-백엔드-데이터베이스 연동 실습 샌드박스
- **`3.autoreport_크롬확장앱/`**: 실제 사내 업무 자동화 크롬 확장 프로그램 소스 및 단계별 자습 교재
- **`docs/`**: 프로젝트 아키텍처, 변경 이력, 트러블슈팅 오답 노트

---

## 학습 시작 방법

1. **`1.교육자료` 폴더**의 문서부터 번호 순서대로 읽기 시작합니다.
2. 교재를 읽다가 모르는 개념이 나오면 `0-3. 나만의_AI_학습위키_확장가이드.md`의 프롬프트를 복사하여 AI에게 질문합니다.
3. **`2.API_TEST`**와 **`3.autoreport_크롬확장앱`** 실습 단계로 넘어가 AI와 함께 실제 프로그램을 실행하고 수정해 봅니다.

## 권장 환경

- **브라우저**: Google Chrome (개발자 모드 활성화)
- **런타임**: Node.js v20 이상
- **개발 도구**: Antigravity IDE 또는 VS Code
- **AI 서비스**: OpenRouter, Google Gemini, Anthropic Claude
