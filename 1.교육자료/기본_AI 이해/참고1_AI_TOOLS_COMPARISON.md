# 📊 AI 도구 및 웹 호스팅 서비스 종합 비교표 (AI_TOOLS_COMPARISON)

> **문서 목적**: 개발 상황과 보안 요구조건에 맞춰 적절한 **AI 바이브 코딩 도구**와 **웹 호스팅 플랫폼**을 선택할 수 있도록 상세 명세와 장단점을 비교·분석한다.

---

## 1. 🤖 AI 개발 도구 (Chat vs CLI vs IDE) 상세 비교

AI 도구는 개발에 얼마나 관여하느냐에 따라 **Chat UI**, **CLI Agent**, **Agentic IDE** 3가지 단계로 진화했다.

```
┌─────────────────────────────────────────────────────────────┐
│ AI 개발 도구 진화 단계                                       │
├─────────────────────────────────────────────────────────────┤
│ 1세대: Chat UI (ChatGPT, Claude.ai)                          │
│   → 복사 & 붙여넣기 중심, 파일 수정 불가능                   │
│                                                             │
│ 2세대: CLI Tools (Claude Code, Aider, OpenHands)             │
│   → 터미널 명령으로 파일 자동 읽기/쓰기, 스크립트 작성 용이  │
│                                                             │
│ 3세대: Agentic IDE (Antigravity, Cursor, Windsurf)           │
│   → 에디터 심층 통합, 전역 Context 색인, 원클릭 diff 반영  │
└─────────────────────────────────────────────────────────────┘
```

### 📊 AI 도구 종합 비교 명세표

| 비교 항목 | 1세대: Chat UI (ChatGPT / Claude) | 2세대: CLI Agent (Claude Code / Aider) | 3세대: Agentic IDE (Antigravity / Cursor) |
|-----------|-----------------------------------|--------------------------------------|-------------------------------------------|
| **주요 서비스** | ChatGPT Web, Claude.ai, Gemini Web | Claude Code, Aider CLI, AutoGPT | Antigravity, Cursor, Windsurf, Copilot |
| **코드 파일 접근**| ❌ 수동 파일 첨부/복붙 필요 | ✅ 터미널 경로의 파일 직접 수정 | ✅ 프로젝트 전체 파일 자동 파싱 및 수정 |
| **Context 이해력**| ⚠️ 입력된 텍스트 범위로 제한됨 | 🟡 지정한 파일 및 Git 변경점 파악 | 🟢 전역 임베딩 색인으로 프로젝트 전체 파악 |
| **코드 반영 방식**| 사용자가 일일이 코드 복붙 | AI가 터미널에서 코드 자동 교체 | UI 상에서 inline Diff 확인 후 승인 |
| **테스트 실행** | ❌ 사용자가 직접 테스트 후 에러 보고 | 🟢 CLI 명령어로 직접 테스트 수행 가능 | 🟢 백그라운드 터미널 및 브라우저 검증 가능 |
| **난이도** | ⭐ 매우 쉬움 (채팅) | ⭐⭐ 보통 (터미널 기초 필요) | ⭐⭐ 보통 (VS Code 사용자 익숙) |
| **추천 용도** | 간단한 알고리즘 질문, 단발성 자문 | 서버 스크립트 작성, 단일 파일 리팩토링| **풀스택 웹앱, Chrome Extension, 대형 프로젝트** |

## 2. 🌐 웹 호스팅 플랫폼 (Web Hosting Services) 비교

내가 만든 웹 애플리케이션을 인터넷 퍼블릭(Public) 환경에 공개할 때 사용하는 대표적 호스팅 서비스들의 특성 비교이다.

```
[호스팅 선택 가이드]

┌─────────────────────────────────────────────────────────────┐
│  Q1. 초보자이고 Git 푸시만으로 1분 배포를 원하는가?        │
│      ➔ 🏆 Vercel 또는 Netlify 추천                           │
│                                                             │
│  Q2. 데이터베이스(DB) 없는 완전한 정적 HTML 페이지인가?      │
│      ➔ 🐙 GitHub Pages 추천                                  │
│                                                             │
│  Q3. 사내 전용 대용량 서버 인프라 및 완벽한 제어가 필요한가? │
│      ➔ ☁️ AWS / GCP / Azure 또는 자체 온프레미스 서버       │
└─────────────────────────────────────────────────────────────┘
```

### 📊 웹 호스팅 서비스 종합 비교 명세표

| 호스팅 서비스 | 무료 제공 (Free Tier) | 난이도 | Git 연동 / CI/CD | HTTPS (SSL) | 주요 특징 및 적합한 상황 |
|---------------|-----------------------|:------:|:----------------:|:-----------:|--------------------------|
| **Vercel** | ✅ 평생 무료 플랜 | ⭐ 쉬움 | ⚡ 완벽 지원 (자동) | 🔒 무료 자동발급 | **(강력 추천)** 프론트엔드/Next.js/HTML 최적화. 1분 배포 |
| **Netlify** | ✅ 평생 무료 플랜 | ⭐ 쉬움 | ⚡ 완벽 지원 (자동) | 🔒 무료 자동발급 | Vercel과 유사. 폼 처리(Form) 및 정적 사이트 우수 |
| **GitHub Pages** | ✅ 완전 무료 | ⭐⭐ 보통 | 🟡 Git 저장소 연동 | 🔒 무료 제공 | `username.github.io` 제공. 정적 HTML/JS만 가능 |
| **AWS / GCP** | ⚠️ 1년 무료 (이후 유료)| ⭐⭐⭐ 어려움 | 🔴 직접 구축 필요 | 🔴 설정 필요 | 기업용 대규모 서비스, 인프라 완벽 제어 가능 |
| **자체 서버 (On-premise)** | ❌ 비용 발생 (서버 구매)| ⭐⭐⭐ 어려움 | 🔴 직접 구축 필요 | 🔴 직접 설치 | 사내망 보안 전용. 외부 인터넷 연결 불가능한 환경 |

## 3. 🎯 학습 상황별 최적 조합 가이던스

### 💡 Case A: 직장인 업무 자동화 (개인용 Chrome Extension)
- **AI 도구**: Antigravity / Cursor (Agentic IDE)
- **호스팅**: **필요 없음 (로컬 실행)**
- **이유**: 사내 ERP 및 업무 데이터 보안을 유지하기 위해 외부 서버 배포 없이 브라우저 로컬 Extension으로만 동작시킴.

### 💡 Case B: 팀원 공유용 자동화 계산기/웹앱
- **AI 도구**: Antigravity / Claude Code
- **호스팅**: **Vercel (GitHub 연동)**
- **이유**: 1분 배포가 가능하며, 팀원들이 복잡한 설치 과정 없이 스마트폰이나 PC 브라우저 URL로 즉시 접속 가능.

### 💡 Case C: 대용량 사내 매뉴얼 검색 Q&A 시스템
- **AI 도구**: Antigravity + RAG Vector DB
- **호스팅**: **사내 자체 서버 (On-premise)**
- **이유**: 5,000페이지 분량의 사내 비밀 매뉴얼 유출 방지를 위한 보안 격리 서버 환경 구축.
